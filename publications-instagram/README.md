## Dans chaque `post.txt`

1. L'en-tête : date et heure, cible, fonctionnalité, format, objectif, remarque.
2. **VISUELS** : pour chaque slide, le texte à mettre sur l'image et la description du visuel (gabarits et couleurs dans
   [`branding/charte-visuelle.md`](../branding/charte-visuelle.md)).
3. **LÉGENDE À COPIER** : la légende complète, avec l'appel à l'action et 4 hashtags maximum.

Les PNG, une fois faits, vont dans le même dossier : `PNN_1-sur-N.png` (HD 2160 × 2700), importés dans l'ordre.
Les stories : PNG 2160 × 3840, sans bandeau de l'interface Instagram. Les stickers (sondage, quiz, lien…) se posent dans
Instagram, pas sur l'image.

## Marqueurs

- `[À COMPLÉTER]` : une info réelle à fournir (capture, citation, date, nombre).
- `[À CONFIRMER]` : une info sur le produit à vérifier avant de publier.

Aucune publication ne doit partir avec un de ces marqueurs.
